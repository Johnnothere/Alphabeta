# Security policy

Found something? Tell us. Builders who report responsibly get thanked in public.

**Report privately** through
[GitHub security advisories](https://github.com/Johnnothere/Alphabeta/security/advisories/new).
Please do not open a public issue for a vulnerability.

What helps: the URL or server function involved, what you sent, what came back,
and what you expected instead. Access-code guessing is rate-limited by design;
please do not run it against the live site.

We aim to acknowledge within a week. The machine-readable version of this file
is at `/.well-known/security.txt`.
